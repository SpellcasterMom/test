# agent.md — рабочие соглашения (проект CLAW, 6DOF)

## Гит
- Работа в ветках, в `master` только принятое на железе; слияние — по команде.
- Несколько машин пушат concurrently: всегда `fetch` перед `push`, чужие коммиты смотреть (`show`/`diff`), мёржить, не перетирать.
- Remote `github` (SpellcasterMom/test) — только по явной команде, иначе молчит.
- Коммиты короткие, по делу; `Last modify` в шапке каждого тронутого файла — обновлять.

## Шапки файлов
- `Project / Codename: CLAW / Author / Alma Mater (два слова!) / Group / Mentor / Date / Last modify`.
- «Alma Mater» — раздельно, это латынь. Исключение — только если вуз официально пишет иначе.

## Зависимости
- **Adafruit — нет** (тяжёлые, Unified Sensor не тащим). Лёгкие (pololu, sparkfun) — только после проверки.
- API чужих либ сверять с исходниками до написания кода (адреса, `Wire.begin` внутри, залипающие статусы, unbounded циклы).
- При сомнениях — голые регистры через Wire (пример: `imu_logger.cpp`).

## I2C
- Шина общая (сервы + датчики): все транзакции под `i2cMutex`, только bounded ожидания (никаких `portMAX_DELAY` на шине), `Wire.setTimeout(20)`.
- Счётчики fails/recovers + самовосстановление (`Wire.end/begin` + переинит регистров).
- Физика: подтяжки 4.7к, шлейф ≤20 см, 400 кГц только на хорошей шине (иначе 100 кГц костылём с пометкой).

## Диагностика
- Boot-лог с маркерами; последняя строка = место останова.
- M115: RESIDUAL — истина; скрипты принимают `OK` и `OK:*`.
- Двойник `tools/twin/` предсказывает сверху, валидирован до 0.1° (трекинг-модель).
- Ворота 10 мм / 15° — святое; отказ лучше прыжка в мусор.
