## Возможности

- **Прямая кинематика (FK)** — DH-параметры, матрицы преобразования 4x4
- **Обратная кинематика (IK)** — геометрические сиды (elbow down/up, нули) с компенсацией несферического запястья + DLS-доводка по полной FK-цепочке + выбор min-residual среди кандидатов (включая доводку от текущей позы)
- **G-code интерфейс** — G0, G1, G28, G90/G91, M104 (через интерполятор), M111 (выучить home), M112, M114/M115 (FK/разбор IK), M414 (палец, сохраняется через M500), M500/M501/M502
- **M115 KIN-DIAG** — цель, кандидаты IK (dPos/dOri/iters/seed), выбранное, факт, расхождение
- **Проверка безопасности** — запретные зоны, прямоугольник workspace, радиусы min/maxReach, zMin по звеньям, виртуальное звено захвата
- **Компенсация люфта** — автоматическая коррекция при смене направления
- **Интерполяция** — линейная/последовательная/автоматическая с ease-in-out; все движения (G0/M104/G28) идут через неё, цели режутся в лимиты серв
- **Экстренная остановка** — M112 во время движения
- **SPI-дисплей** — TCP позиция, углы сервоприводов, захват, статус (READY/ABS/REL/счётчик), safety/PCA, последняя команда; обновление каждые 200 мс
- **EEPROM** — сохранение/загрузка конфигурации (M500/M501/M502)

## Архитектура

```
Core 0 — Serial + Motion
  чтение Serial → парсинг G-code → IK/FK → safety → интерполяция → PCA9685

Core 1 — Display
  чтение SharedState → обновление ST7789 каждые 200мс
```

Доступ к общим данным защищён мьютексами (angleMutex, displayMutex).

## Справочник команд

Движение: `G0`/`G1` (IK/углы),
`M104` (углы), `G28` (home), `G90`/`G91`.

- `G0 X.. Y.. Z..` — ход к TCP (IK).
  `A.. B.. C..` — ориентация, без них +X.
  Незаданные оси — держать. `F..` — подача.
- `G1 ...` — как `G0`, с подачей `F`.
- `G0 P1=.. .. P7=..` — ход в joint-space.
- `G28` / `G28 H1` — home / парковка.
- `G90` / `G91` — абс./отн. режим.
  В `G91` ось = текущий TCP + дельта.
- `M104 P1=.. [F..]` — плавный заезд серв
  (ease-in-out, лимиты, safety).
- `M105` — углы серв.
- `M114` — FK: TCP + цепочка J0..J6.
- `M115 [S=1]` — разбор: цель, кандидаты,
  выбор, факт, расхождение.
- `M111` — выучить home (**!** меняет `G28`).
- `M112` — аварийный стоп.
- `M400 P1=..` — люфт сервы (°).
- `M410` — добавить запретную зону:
  `X1= X2= Y1= Y2= Z1= Z2=`.
- `M411 Z0=..` — стол zMin.
- `M412 R=..` / `M413 R=..` — max/min вылет.
- `M414 L=..` — палец (**+ `M500`**!).
- `M415`/`M416` — safety выкл/вкл
  (алиасы `M425`/`M426`).
- `M417` — список запретных зон.
- `M420 Ln Z=..` — zMin звена n.
- `M430 S=0..3` — linear/seq/groups/auto.
- `M500`/`M501`/`M502` — сохранить,
  загрузить, заводские.
- `?` — справка.

Примеры:

```text
G28
# нули: вертикально, инструмент +X
M104 P1=0 P2=0 P3=0 P4=0 P5=0 P6=0
M114  # FK: TCP = (132, 53, 514)
G0 X200 Y200 Z200 A0 B146 C45  # T1
G91
G0 X20 Y20 Z20  # +20 мм от текущей
G90
M115  # разбор последнего хода
```

`M115` читается сверху вниз:
- `TARGET` — куда просили (позиция + ориентация; `(orient=default)` = подставлен дефолт +X);
- `SOLS` — кандидаты IK (down/up/нули/текущая):
  - `dPos`/`dOri` — расхождения кандидата (мм/град);
  - `NLS:ok/4it` — сошёлся ли DLS и за сколько итераций (`fail` = упёрся в лимит итераций);
  - `seed=` — расхождение стартового сида (мм/град);
  - `SAFE` — прошёл ли safety (`FAIL(причина)` = чем забракован);
  - `CLAMP:P..` — какие суставы сидят на механических лимитах;
- `CHOSEN` — выбор min-residual (`dPos` + `dOri`) среди безопасных;
- `ACTUAL` — куда реально поехали (углы + FK);
- `RESIDUAL` — итог: факт минус цель.

Отказ `No accurate safe IK` = лучший безопасный кандидат хуже 10 мм / 15° — рука не едет в мусор.

## Распиновка и карта серв

| Канал PCA9685 | Сустав         | Серва                       | MATH-лимит | Скорость |
|---------------|----------------|-----------------------------|------------|----------|
| 0             | P1 Base        | 20 кг DS3218, 4.8–6.8 В     | ±135°      | 30°/с    |
| 1             | P2 Shoulder    | 70 кг BLS-HV70MG, 4.8–8.4 В | ±135°      | 30°/с    |
| 2             | P3 Elbow       | 70 кг BLS-HV70MG, 4.8–8.4 В | ±135°      | 30°/с    |
| 3             | P4 Wrist pitch | MG90S 2.5 кг, 4.8 В         | ±90°       | 180°/с   |
| 4             | P5 Wrist roll  | MG90S 2.5 кг, 4.8 В         | ±90°       | 180°/с   |
| 5             | P6 Wrist yaw   | MG90S 2.5 кг, 4.8 В         | ±90°       | 180°/с   |
| 6             | P7 Gripper     | MG90S 2.5 кг, 4.8 В         | 0–100%     | 90°/с    |

- PCA9685: I2C SDA=21, SCL=22. Дисплей ST7789 240×240: SPI MOSI=23, SCK=18, CS=5, DC=2, RST=4.
- MATH-угол 0 = середина сервы (offset 135° для 270°-серв P1–P3, 90° для 180°-серв P4–P6).
- Все движения (G0/M104/G28) идут через интерполятор: ease-in-out, лимиты скоростей не пробиваются, цели режутся в лимиты углов.

## Ручной пульт (ветка `feat-jog-pendant`)

- Штурвал EC11 + кнопка NEXT + кнопка
  E-STOP. Всё на пинах ESP32.
- NEXT листает канал P1..P7 (захват тоже).
- Штурвал: 1°/детент (P1–P6),
  2%/детент (захват). Ход через `moveTo`
  (лимиты, safety, ease-in-out).
- E-STOP — отдельный пин, просто кнопка:
  только стоп движения, сервы под током.
  Вооружён всегда, даже без пульта.
- Пины: A=32, B=33, NEXT=25, ESTOP=26.
- Выбор канала — в Serial (`JOG: channel`).

## Кинематика

- Рамка: **+X вперёд, +Y влево, +Z вверх**, стол = XY, origin = центр основания.
- DH — по чертежу [`docs/robot1.jpg`](docs/robot1.jpg) (таблица выше), запястье **не сферическое** (J4→O6 ~107 мм).
- Нулевая поза (все q=0): рука вертикально, инструмент +X, TCP = (132, 53, 514).
- Кинематический палец **132 мм** = 27 (J6→фланец) + 105 (захват). Команда задаёт TCP = кончик захвата.
- Дефолтная ориентация G0 без A/B/C: (90, 0, 90) = палец +X (поза нулей).
- Домашняя поза по умолчанию: {0, −30, −135, 0, 0, 0} (сложенная вперёд); нули — «вверх + захват в горизонте».

## Safety и workspace

- Прямоугольник: X/Y ±560, Z 0–700 (истинные габариты robot1 + запас).
- Цилиндр: maxReach 560, minReach 0;
  zMin по звеньям {0, 0, 10, 10, 10, 10}.
- Запретные зоны: `M410`/`M417`. Отказ движения = `ERROR: ...` + причина в `M115` (`failReason`).
- Статика не проверяется: звено 0 (колонна J0→J1)
  пропущено всегда — оба конца зафиксированы.
  У зон есть маска `skipLinks` (конструктив
  пропускает 0,1,2). Не считаем столкновение
  того, что столкнуться не может.
- Порог годности IK: лучший безопасный кандидат хуже 10 мм / 15° → отказ (`No accurate safe IK`).

## FAQ (грабли)

- **После прошивки: `M502` → `M500` → ребут.** Иначе в EEPROM лежат старые DH/палец/лимиты safety, symptoms — любые.
- **`M115`, поле `FINGER`** — должно быть 105.0. Если другое: `M414 L105` + `M500` + ребут.
- **`M111` переопределяет home** (потом `G28` едет туда). Не нажимать случайно; чинится `M502`+`M500`.
- **`No safe IK solution`** — все кандидаты опасны (стол/зоны/короб). Смотреть `M115`: TARGET и `failReason`.
- **`No accurate safe IK (best dPos=.. dOri=..)`** — безопасные есть, но все мимо: цель вне декстерусного workspace (типично дальний край + крутой инструмент). Менять подход, не толкать.
- **G91 не едет?** Проверить `M115`, поле `MODE` (REL/ABS). Цель в REL = текущий TCP + дельта.
- **Дисплей врёт после прямых команд?** Лечится само (состояние пушится), проверить счётчик команд на экране.
