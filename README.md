# 6DOF Robot Arm Controller

Контроллер 6-осевого робота-манипулятора на ESP32 + PCA9685.
Группа: УТС/б-23-1-о.

## Оборудование

| Компонент | Модель |
|-----------|--------|
| Микроконтроллер | ESP32 (2 ядра, 240 МГц) |
| Драйвер сервоприводов | PCA9685 (I2C: SDA=21, SCK=22) |
| Дисплей | ST7789 1.54" 240x240 (SPI: MOSI=23, SCK=18, CS=5, DC=2, RST=4) |
| Сервоприводы | 7 шт: 20кг (Base), 70кгx2 (Shoulder, Elbow), MG90Sx3 (Wrist), MG90S (Gripper) |

## Возможности

- **Прямая кинематика (FK)** — DH-параметры, матрицы преобразования 4x4
- **Обратная кинематика (IK)** — геометрические сиды (elbow down/up, нули) с компенсацией несферического запястья + DLS-доводка по полной FK-цепочке + выбор min-residual среди кандидатов (включая доводку от текущей позы)
- **G-code интерфейс** — G0, G1, G28, G90/G91, M104 (через интерполятор), M111 (выучить home), M112, M114/M115 (FK/разбор IK), M414 (палец, сохраняется через M500), M500/M501/M502
- **M115 KIN-DIAG** — цель, кандидаты IK (dPos/dOri/iters/seed), выбранное, факт, невязка
- **Проверка безопасности** — запретные зоны, прямоугольник workspace, радиусы min/maxReach, zMin по звеньям, виртуальное звено захвата
- **Компенсация люфта** — автоматическая коррекция при смене направления
- **Интерполяция** — линейная/последовательная/автоматическая с ease-in-out; все движения (G0/M104/G28) идут через неё, цели режутся в лимиты серв
- **Экстренная остановка** — M112 во время движения
- **SPI-дисплей** — TCP позиция, углы сервоприводов, захват, статус (READY/ABS/REL/счётчик), safety/PCA, последняя команда; обновление каждые 200 мс
- **EEPROM** — сохранение/загрузка конфигурации (M500/M501/M502)

## Архитектура

```
Core 0 — Serial + Motion
  чтение Serial → парсинг G-code → IK/FK → safety → интерполяция → PCA9685

Core 1 — Display
  чтение SharedState → обновление ST7789 каждые 200мс
```

Доступ к общим данным защищён мьютексами (angleMutex, displayMutex).

## DH-параметры

| Звено | a (мм) | alpha (°) | d (мм) | theta_off (°) |
|-------|--------|-----------|--------|-----------------|
| 1 | 0 | 90 | 134 | 0 |
| 2 | 165 | 0 | 0 | 90 |
| 3 | 161 | 0 | 0 | 0 |
| 4 | 54 | 90 | 0 | 0 |
| 5 | 53 | -90 | 0 | -90 |
| 6 | 0 | 90 | 0 | 0 |

Кинематический палец (O6 → TCP): 132 мм = 27 (J6 → фланец) + 105 (захват).
Нули FK: TCP = (132, 53, 514), инструмент +X (чертёж robot1).

## Сборка

```bash
# Требуется PlatformIO
pio run -t upload
pio device monitor
```

## Приёмка после прошивки

```text
M502            # заводские (DH robot1, палец 132, лимиты safety)
M500            # сохранить в EEPROM
<ребут>
M115            # проверить FINGER: 132.0
M104 P1=0 P2=0 P3=0 P4=0 P5=0 P6=0
M114            # нули FK: TCP = (132, 53, 514)
<рулетка в нулях: ±2–3 мм>
G0 X200 Y200 Z200 A0 B146 C45
M115            # T1: dPos ≤ 1 мм, dOri — единицы градусов
```

## Ветки

| Ветка | Содержимое |
|-------|------------|
| `master` | стабильная линия |
| `fix-g91-rel` | рабочий G91 (смещение от текущего TCP, поосевое удержание), отказ при плохой невязке (>10 мм / >15°), дефолтная ориентация +X (90, 0, 90) |
| `fix-display-status` | компоновка статус-бара дисплея (ABS/REL, последняя команда) |

## Структура проекта

```
src/
  main.cpp                — FreeRTOS, обработчики команд, дисплей
  config.h                — константы, DH-параметры, ограничения
  types.h                 — Vec3, Mat4, JointAngles, Pose, GCodeCommand
  commands.h              — таблица команд (G0, G1, G28, M104...)
  fk_solver.h/.cpp        — прямая кинематика (DH)
  ik_solver.h/.cpp        — обратная кинематика (геометрия + DH)
  servo_controller.h/.cpp — PCA9685, управление сервоприводами
  motion_interpolator.h/.cpp — интерполяция движений
  safety_checker.h/.cpp   — проверка безопасности
  backlash_compensator.h/.cpp — компенсация люфта
  gripper_controller.h/.cpp — управление захватом
  gcode_parser.h/.cpp     — парсер G-code
  eeprom_storage.h/.cpp   — хранение конфигурации
```
