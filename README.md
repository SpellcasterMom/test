## Возможности

- **Прямая кинематика (FK)** — DH-параметры, матрицы преобразования 4x4
- **Обратная кинематика (IK)** — геометрические сиды (elbow down/up, нули) с компенсацией несферического запястья + DLS-доводка по полной FK-цепочке + выбор min-residual среди кандидатов (включая доводку от текущей позы)
- **Декартов ход G1** — TCP по прямой (lerp + slerp через ось-угол, без эйлеров внутри), IK-трекинг на каждом шаге, стоп на последнем хорошем
- **Планировщик объезда** — via-точки у граней коробов + RRT в joint-space (детерминированный сид), исполнение цепочкой вейпоинтов
- **G-code интерфейс** — G0, G1, G28 (+H1, +F), G90/G91, M104 (через интерполятор), M108 (захват в %), M111 (выучить home), M112, M114/M115 (FK/разбор IK), M119 (IMU: живые/дамп), M414 (палец, сохраняется через M500), M500/M501/M502
- **M115 KIN-DIAG** — цель, запястье, кандидаты IK (dPos/dOri/iters/seed/minZ/CLAMP), выбранное, вейпоинты, факт, расхождение, причина отказа
- **Проверка безопасности** — запретные зоны (+бокс конструктива колонны), прямоугольник workspace, радиусы min/maxReach, zMin по звеньям, виртуальное звено захвата
- **Компенсация люфта** — автоматическая коррекция при смене направления
- **Интерполяция** — линейная/последовательная/автоматическая с ease-in-out; все движения (G0/G1/M104/M108/G28) идут через неё, цели режутся в лимиты серв
- **Экстренная остановка** — M112 во время движения (проверяется на каждом шаге)
- **Старт с заездом** — при включении рука сама едет парк→home тихо (F15): держите зону свободной! Калибровка нуля гиро — только при наличии GY-80 (статус `>> CALIB` на экране)
- **SPI-дисплей** — TCP позиция + Roll/Pitch/Yaw, углы сервоприводов, захват %, версия FW в шапке, статус (READY/MOVING/ERROR/CALIB, ABS/REL, счётчик), safety текстом + PCA/GYR кружками наличия (зелёный/красный; GYR жёлтый = только гиро), последняя команда; обновление каждые 200 мс
- **IMU-логгер** — GY-80 опрашивается 200 Гц на Core 1 (голые регистры, без сторонних либ), кольцевой журнал последнего движения (1024 сэмпла: время + сырые counts), выдача хосту командой M119
- **EEPROM** — сохранение/загрузка конфигурации (M500/M501/M502), версия FW с авто-миграцией

## Архитектура

```
Core 0 — Serial + Motion
  чтение Serial → парсинг G-code → IK/FK → safety → интерполяция → PCA9685

Core 1 — Display + IMU
  чтение SharedState → обновление ST7789 каждые 200мс
  опрос GY-80 каждые 5мс → комплементарный фьюжн наклона → кольцо (пока isMoving)
```

Доступ к общим данным защищён мьютексами (angleMutex, displayMutex, i2cMutex — шина Wire общая для PCA9685 и GY-80).

## Справочник команд

Движение: `G0`/`G1` (IK/углы),
`M104` (углы), `G28` (home), `G90`/`G91`.

- `G0 X.. Y.. Z..` — ход к TCP (IK).
  `A.. B.. C..` — ориентация, без них +X.
  Незаданные оси — держать. `F..` — подача.
- `G1 ...` — как `G0`, TCP строго по прямой, `F` обязательна для темпа.
- `G0 P1=.. .. P7=..` — ход в joint-space.
- `G28 [H1] [F..]` — home / парковка / подача (без F — 300; `F15` = тихо, так едет старт).
- `G90` / `G91` — абс./отн. режим.
  В `G91` ось = текущий TCP + дельта.
- `M104 P1=.. [F..]` — плавный заезд серв
  (ease-in-out, лимиты, safety).
- `M105` — углы серв.
- `M108 S=..` — захват в процентах (0=закрыт,
  100=открыт; шкала P7 0..100, калибровки
  миллиметров губок нет — проценты условные).
- `M114` — FK: TCP + цепочка J0..J6.
- `M115 [S=1]` — разбор: цель, запястье,
  кандидаты, выбор, вейпоинты, факт,
  расхождение, причина отказа.
- `M111` — выучить home (**!** меняет `G28`).
- `M112` — аварийный стоп.
- `M119` — IMU живьём (наклон, counts,
  bias, пики, счётчик, шина fails/recovers).
- `M119 S=1 [D=n]` — дамп кольца (`#IMU`
  строки + `OK`; D — каждый N-й).
- `M400 P1=..` — люфт сервы (°).
- `M410 X= Y= Z= A= B= C=` — добавить запретную
  зону (границы x1,x2,y1,y2,z1,z2; только рантайм,
  ребут смывает; конструктив колонны — всегда).
- `M411 Z=..` — стол zMin.
- `M412 R=..` / `M413 R=..` — max/min вылет.
- `M414 L=..` — палец в мм (**+ `M500`**!).
- `M415`/`M416` — safety выкл/вкл
  (алиасы `M425`/`M426`).
- `M417` — список запретных зон.
- `M420 L.. Z=..` — zMin звена n.
- `M430 S=0..3` — linear/seq/groups/auto.
- `M500`/`M501`/`M502` — сохранить,
  загрузить, заводские.
- `?` — справка (там же версии FW/HW).

Примеры:

```text
G28
# нули: вертикально, инструмент +X
M104 P1=0 P2=0 P3=0 P4=0 P5=0 P6=0
M114  # FK: TCP = (132, 53, 514)
G0 X200 Y200 Z200 A90 B0 C90  # T1
G91
G0 X20 Y20 Z20  # +20 мм от текущей
G90
M115  # разбор последнего хода
```

`M115` читается сверху вниз:
- `CMD` — эхо команды; `KIND` — тип (`IK`/`DIRECT`/`HOME`/`PARK`/`CART`), `FEED`, `SAFETY: ON/OFF`, `FINGER` (длина пальца, дефолт 105.0), `MODE: ABS/REL`, `FW` (строка версии, без HW);
- `STRAT` — стратегия выбора (3=auto), `INTERP` — исполнение (`LIN steps/timeMs`, `CART ...` или `DET n`; `NONE no motion` = отказано до движения, смотреть `FAIL`);
- `TARGET` — куда просили (позиция + ориентация; `(orient=default)` = подставлен дефолт +X);
- `TARGET wrist / toolDir` — запястье = TCP − палец вдоль направления инструмента (то, что реально решает геометрия);
- `SOLS` — кандидаты IK (down/up/нули/текущая):
  - `dPos`/`dOri` — расхождения кандидата (мм/град; `dOri` = угол между осями инструмента, roll вокруг пальца не видит);
  - `NLS:ok/4it` — сошёлся ли DLS и за сколько итераций (`fail` = упёрся в лимит итераций; `fail` — норма, ворота решают);
  - `seed=` — расхождение стартового сида (мм/град); `dq0` — норма первого шага DLS, `n1` — расхождение после него;
  - `SAFE` — прошёл ли safety (`FAIL(причина)` = чем забракован);
  - `CLAMP:P..` — какие суставы сидят на механических лимитах (хроника: P4 в упоре почти везде с инструментом +X);
  - `minZ=` — минимальная высота цепочки J2..J6 (ниже 150 — высотный штраф в выборе);
- `CHOSEN` — выбор min-residual с биасами (`dPos` + `dOri` + 0.02·прыжок + высотный штраф), не чистый минимум;
- `WPS: n` — вейпоинты объезда (`1` = прямой ход), дальше строки `  [i] X= Y= Z=`;
- `ACTUAL` — куда реально поехали (углы + FK по суставам J0..J6 + `DIR`/`TCP`);
- `RESIDUAL` — итог: факт минус цель (`dX/dY/dZ/dist/dOri`); должен совпасть с `dPos`/`dOri` выбранного кандидата;
- `FAIL`/`failReason` — причина отказа (`No accurate safe IK (best ...)` = лучший безопасный хуже 10/15).

Отказ `No accurate safe IK` = лучший безопасный кандидат хуже 10 мм / 15° — рука не едет в мусор.

## Ручной пульт

- Штурвал EC11 + кнопка NEXT + кнопка
  E-STOP. Всё на пинах ESP32.
- NEXT листает канал P1..P7 (захват тоже).
- Штурвал: 1°/детент (P1–P6),
  2%/детент (захват). Ход через `moveTo`
  (лимиты, safety, ease-in-out).
- E-STOP — отдельный пин, просто кнопка:
  только стоп движения, сервы под током.
  Вооружён всегда, даже без пульта.
- Пины: A=32, B=33, NEXT=25, ESTOP=26.
- Выбор канала — в Serial (`JOG: channel`).

## Удалённый доступ (TCP-мост)

Прошивка говорит по Serial; для удалённой работы порт пробрасывается в TCP (socat на машине с железом):

```bash
# освободить порт (закрыть монитор/скрипты!), затем:
socat TCP-LISTEN:5000,fork,reuseaddr /dev/ttyUSB0,raw,echo=0,b921600
# проверка (вторым терминалом):
echo "M105" | nc localhost 5000   # в ответ Angles:...
```

- Скорость моста = скорости прошивки (`SERIAL_BAUD`, сейчас 921600), иначе мусор/молчание.
- Хозяин порта один: пока идёт удалённая сессия — локальные монитор/скрипты закрыты (два читателя рвут ответы пополам).
- Мост и проброс гасить после сессии (открытый G-code порт = anyone drives the arm).
- Клиент: `tools/tcp_console.py HOST PORT ["CMD"]` (таймауты с запасом на сеть).

## Safety и workspace

- Прямоугольник: X/Y ±560, Z 0–700 (истинные габариты robot1 + запас).
- Цилиндр: maxReach 560, minReach 0;
  zMin по звеньям {0, 0, 10, 10, 10, 10}.
- Запретные зоны: `M410`/`M417` (только рантайм — ребут смывает; конструктив колонны [-65,65]²×[0,180] — всегда). Отказ движения = `ERROR: ...` + причина в `M115` (`failReason`).
- Статика не проверяется: звено 0 (колонна J0→J1)
  пропущено всегда — оба конца зафиксированы.
  У зон есть маска `skipLinks` (конструктив
  пропускает 0,1,2). Не считаем столкновение
  того, что столкнуться не может.
- Самопересечения звеньев — в работе (ветка `feat-self-collision`, модель-капсулы в `tools/twin/selfcol.py`): звено 2→3 смещено на 59 мм вдоль оси J2.
- Порог годности IK: лучший безопасный кандидат хуже 10 мм / 15° → отказ (`No accurate safe IK`).

## FAQ (грабли)

- **После прошивки: `M502` → `M500` → ребут.** Иначе в EEPROM лежат старые DH/палец/лимиты safety, symptoms — любые.
- **При старте рука сама едет парк→home (F15).** Держите зону свободной. Не запарковались перед выключением — заезд будет из неверной точки (конвенция: `G28 H1` перед выключением).
- **Скорость порта везде 921600** (прошивка `SERIAL_BAUD` + `monitor_speed` + скрипты + socat). Рассинхрон = тишина; мусор при ребуте — boot-ROM на 115200, косметика.
- **`M115`, поле `FINGER`** — должно быть 105.0. Если другое: `M414 L105` + `M500` + ребут.
- **`M111` переопределяет home** (потом `G28` едет туда). Не нажимать случайно; чинится `M502`+`M500` (home слетает в дефолт — переучить!).
- **`No safe IK solution`** — все кандидаты опасны (стол/зоны/короб). Смотреть `M115`: TARGET и `failReason`.
- **`No accurate safe IK (best dPos=.. dOri=..)`** — безопасные есть, но все мимо: цель вне декстерусного workspace (типично дальний край + крутой инструмент). Менять подход, не толкать.
- **G91 не едет?** Проверить `M115`, поле `MODE` (REL/ABS). Цель в REL = текущий TCP + дельта.
- **Перед выключением — `G28 H1` (парк).** Старт всегда едет парк→home тихо (F15), считая что рука ночевала в парке. Не запарковался — заезд будет из неверной точки: рука должна стоять свободно. Точные углы парка — в `DEFAULT_PARK_ANGLES` (`config.h`).
- **Дисплей врёт после прямых команд?** Лечится само (состояние пушится), проверить счётчик команд на экране.
