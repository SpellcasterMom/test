# tools — питон-инструменты

Раннеры демо (Serial), TCP-клиент и двойник кинематики
(офлайн-валидация без железа). Скорость порта везде 921600
(синхронно с `SERIAL_BAUD` прошивки и `monitor_speed`).

## Раннеры (запуск из этого каталога)

- `demo.py` — endpoint-демо из шапки `main.cpp`
  (12 шагов, TCP стоит).
- `demo_endpoint.py` — то же + разбор M115 по шагам.
- `demo_circle.py [/dev/ttyUSB0] [tilt|plusx]` — круг r=100
  в наклонной плоскости (24 точки G1 + разбор M115
  + полный дамп в `circle_*.log`). Пресет `tilt` (дефолт):
  tilt-профиль A/B/C, 24/24 OK; `plusx` — строгий +X
  (воспроизводит честные отказы).
- `jogger.py /dev/ttyUSB0` — джог серв с клавиатуры:
  пары `q/a=P1 … u/j=P7` (+/−), строчная = 5°,
  заглавная = 25°, `0` = все в 0 (лимиты ±135/±90/7–38
  режутся локально), `~` = M105, `?` = помощь, Esc = выход.
- `tcp_console.py HOST PORT ["CMD"]` — G-code по TCP-мосту
  (socat на машине с железом), разово или интерактивно.

Всем Serial-раннерам нужен `pip install pyserial`, порт
автоопределяется (`... /dev/ttyUSB0` вручную).
Логи прогонов (`circle_*.log` и т.п.) в репо не коммитим.

## twin/ — двойник FK/IK (зеркало прошивки 1:1)

- `fk.py`, `ik.py`, `solve.py` — FK, DLS, полный
  `solve()` (сиды + min-residual).
- `accept.py`, `accept_loops.py`, `check_conv.py` —
  приёмки сходимости и кругов.
- `detour.py` — зеркало планировщика объезда
  (via-точки + RRT, те же пороги).
- `verify_low.py` — проверка низких точек.
- `dh_draw.py`, `check.py`, `opt.py`, `fit2.py`,
  `fit3.py` — история вывода DH (архив).
- `demo_endpoint.py` → `endpoint_sweep.py` — свип
  ориентаций (архив).
- `cart_test.py` — математика декартового G1.
- `circle_tilted.py` — подбор наклонного круга.
- `workspace_stl.py` — воксель → `reach.stl`.

Правило: любая правка кинематики сначала
доказывается здесь, потом едет в `src/`.
