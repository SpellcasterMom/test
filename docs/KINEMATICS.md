# Как считается кинематика (референс, не править без нужды)

Рамка: +X вперёд, +Y влево, +Z вверх. Стол = XY, origin = центр
основания. Углы — математические (ноль плеча = вертикаль).

## FK: DH-цепочка (чертёж robot1, `docs/robot1.jpg`)

| # | a | alpha | d | off | смысл |
|---|---|-------|---|-----|-------|
| 1 | 0 | +90 | 134 | 0 | база → плечо |
| 2 | 165 | 0 | 0 | +90 | плечо → локоть |
| 3 | 161 | 0 | 0 | 0 | локоть → J4 |
| 4 | 0 | −90 | 0 | −90 | J4 (оси J4/J5 пересекаются) |
| 5 | 53 | +90 | 54 | +90 | J5 → J6 |
| 6 | 0 | 0 | 27 | 0 | J6 → фланец |

Оси нулей: J1=Z, J2=J3=J4=−Y, J5=+Z, **J6=+X (roll вокруг
инструмента — проверено железом: P6 крутит захват на месте,
TCP стоит)**. Запястье НЕ сферическое. Палец 105 = захват
(J6→фланец 27 сидит в DH как d звена 6). Нули FK: TCP=(132,53,514),
инструмент +X. Лимиты: P1–P3 ±135°, P4–P6 ±90°, скрость 45/45/45.

## IK: сиды + DLS-доводка (матричное расхождение)

1. Цель TCP → запястье: `w = TCP − toolDir·палец`.
2. Сиды q1–q3: геометрия двухзвенника 165+161 с компенсацией
   запястья (fixed-point J4←O6, `seedArm`) + elbow down/up + нули
   + доводка от текущей позы. Всего до 4.
3. Сиды q4–q6: `R36 = R03ᵀ·R06`, декомпозиция (для сидов сойдёт).
4. Доводка DLS по ПОЛНОЙ цепочке: расхождение = позиция (мм) +
   axis-angle от `R_err = Rt·Rᵀ` × вес 30 (без эйлеров внутри —
   там нет разрывов свёртки). λ=0.3 адаптивная, line search,
   active-set на лимитах, допуски 1 мм / 1°.
5. Выбор: min-residual `dPos + dOri + 0.02·прыжок + высотный
   штраф 0.05·max(0,150−minZ)`. Порог годности 10 мм / 15° —
   хуже не едем, стоим с ошибкой.

## Декарт (G1): TCP по прямой

Позиция lerp + ориентация slerp (ось-угол `R0ᵀ·R1`, Rodrigues),
эйлеры разворачиваются к предыдущему шагу (без snap'ов),
каждый шаг — IK от предыдущего (трекинг) + safety. Срыв —
стоп на последнем хорошем. Эйлеры живут только на входе
(G-code) и в M115; внутри — матрицы.

Проверено: двойник `tools/twin` (зеркало 1:1) предсказывает
железо в десятых (T1 0.0/0.0, круг 1.9/9.1).
