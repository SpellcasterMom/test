# CAD — 3D-модели (STEP)

Каталог для 3D-моделей манипулятора в формате STEP (.step / .stp).
За старт взят проект https://www.printables.com/model/971320-6dof-robot-arm-modular-cheap-educational
Доработано, основание, корзины, штанги, валы

Происхождение геометрии: чертёж [`docs/robot1.jpg`](../docs/robot1.jpg).

Соглашение об именах: `узел_деталь_версия.step`, например
`base_v1.step`, `shoulder_link_v2.step`, `wrist_assembly_v1.step`.

Готовые модели:
- `reach.stl` — внешняя поверхность достижимого объёма TCP
  (800 тыс. сэмплов FK, воксель 12 мм, marching cubes —
  гладкая, без ступенек; генератор `tools/twin/workspace_stl.py).
  Купол минус колонна базы = «шляпка гриба» с чашкой внутри
  (чашка открыта вниз — замкнутых пустот нет, проверено).
  X/Y ±480, Z 6–606, R до ~500.
- `base_column.stl` — колонна базы (R=70, H=134, оценка —
  померяйте штангеном!) для сборки купола на ножку.
- `dex_x.stl`, `dex_down.stl` — ДЕКСТЕРУСНЫЕ ядра: где держится
  инструмент +X (27% позиций) и вниз (12%). Вот честная
  рабочая зона под конкретную ориентацию — остальное
  только точки без гарантии инструмента.
  Это позиции (кончик достаёт хоть как-то);
  декстерусность (с нужной ориентацией) уже.
