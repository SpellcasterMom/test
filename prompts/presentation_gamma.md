## Блок 2. Фактура проекта (нейронке — только эти факты, без галлюцинаций)

- Объект: настольный 6-осевой манипулятор CLAW (дипломный проект).
- Железо: ESP32 (2 ядра), сервы 7 шт через PCA9685
  (P1–P3: 270°, ±135°; P4–P6: 180°, ±90°; P7 захват 0–100%),
  IMU GY-80 (гироскоп + акселерометр), дисплей ST7789, пульт-джоггер.
- Кинематика: таблица Денавита–Хартенберга (звенья 134/165/161/0/53+54/27 мм,
  палец захвата 105 мм, запястье НЕ сферическое); нули дают TCP (132, 53, 514).
- Обратная кинематика: геометрические сиды + доводка Левенберга–Марквардта
  по полной цепочке; выбор min-residual со штрафами (непрерывность + высота).
- Ворота годности: 10 мм / 15°. Хуже — честный отказ с причиной, а не движение в мусор.
- Планировщик объезда запретных зон (via-точки + RRT), телеметрия IMU (M119).
- Валидация двойником (Python-зеркало прошивки), цифры:
  точка T1 (200,200,200) — 0.5 мм / 12.2°;
  наклонный круг r=100 — 24/24 без отказов, пик 0.3°;
  свип 168 точек с препятствиями — принято 67, решений под столом ноль;
  недоступные точки отбиваются честно (пример: 2.2 мм / 16.5° — отказ).

## Блок 4. Требования к стилю (дописать в Gamma при генерации, если умеет)

- Строго русский язык, термины как в блоке 2 (TCP, DLS, RRT, ворота — без перевода).
- Каждый слайд с цифрами: только цифры из блока 2, ничего округлённого «на глаз».
- Никаких выдуманных графиков/процентов/«улучшений в N раз».
- Место под 4 вставки пометить плейсхолдерами: [ЧЕРТЁЖ], [ФОТО РУКИ],
  [КУСОК M115], [БЛОК-СХЕМА].
